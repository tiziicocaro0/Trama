# Trama

Trama es una plataforma colaborativa que busca facilitar la comunicación y el seguimiento interdisciplinario de niños con Trastorno del Espectro Autista (TEA), conectando a familias, profesionales y educadores.

## Requisitos

Para ejecutar el proyecto localmente se necesita:

- Java 21
- Node.js
- Docker
- Git
